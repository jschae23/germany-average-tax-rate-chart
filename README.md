# Germany Average Tax Rate Chart

This is a simple interactive chart using chart.js displaying the average tax rate for yearly income brackets in Germany for the year 2026. The data has been taken from https://steuertabelle.org/Steuersatz-Tabelle.php and assumes a person is not married.
